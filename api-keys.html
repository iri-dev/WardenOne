How to get your API keys.

Seven threat-intelligence services can plug into WardenOne. You get the keys from the providers themselves, on their own free tiers, and paste them into the popup. This page explains what each one adds and walks through the sign-up for every one of them.

What each key actually adds.

Every provider here is optional. WardenOne's blocklists, download grading, phishing heuristics, and page protection all run without a single key. A key turns on live lookups, which means the URL, domain, or IP being checked is sent to that provider — nothing else goes with it.

Phishing

Phishing intelligence

Lists of URLs that are actively stealing logins right now. These sharpen fake-login detection on links, forms, pastes, page loads, and download flows.

OpenPhishNo key

A public feed of confirmed phishing URLs. WardenOne downloads the Community feed, keeps up to 25,000 URLs cached on your device, and refreshes it every 12 hours, so matching happens locally with no per-page request. This is the cheapest upgrade to fake-login detection on the list.

No key required. Turn it on and press its Test button. The token field is reserved for OpenPhish's paid feed.
PhishTankApproval

A community-verified phishing database, queried one URL at a time. It catches sites that are confirmed and still online, which is the case OpenPhish's snapshot can miss between refreshes. Verified current phishing URLs get blocked outright.

Free, but the application key is issued by approval rather than instantly. If PhishTank answers with a rate limit, WardenOne saves the key and retries later.
Core

URL and file reputation

Verdicts on a specific link or file from engines that have already seen it. These are the two keys that most change what Download Shield knows.

Google Safe BrowsingFree key

The same list Chrome uses, queried directly for malware, social engineering, unwanted software, and harmful applications. With the key in place, WardenOne runs the check on downloads, dangerous page visits, suspicious links, and the destination a sensitive form is about to post to.

Free to use. Google does not publish a fixed free quota — each project gets an allowance you can see, and ask to raise, in the Cloud Console. Needs a Google Cloud project with the Safe Browsing API switched on.
VirusTotalFree key

Aggregated verdicts from dozens of antivirus engines. It powers three things: URL reports during download grading, the paste-a-link scanner in the popup, and the hash lookup for risky files. For the hash lookup WardenOne re-fetches up to 50 MB from the download URL, hashes it on your machine, and sends only that hash — the file itself is never uploaded.

The free public key allows 4 lookups a minute and 500 a day, and is for personal, non-commercial use. WardenOne caches results and only asks about things it already considers risky, so the limit is hard to reach.
Sources

Malware delivery and servers

Where the file is coming from, rather than what the file is. Useful when a download looks ordinary but the host serving it does not.

URLhausFree key

abuse.ch's record of URLs and hosts caught distributing malware. WardenOne can ask about the exact URL or the host behind it, and blocks known malware delivery addresses in page, link, form, paste, and download flows. This is the check that catches a fresh payload on a host that no reputation engine has scored yet.

Free, but abuse.ch now requires an account and an Auth-Key even on the free tier.
AbuseIPDBFree key

Abuse reports for a raw IP address, covering the last 90 days. It applies when a link or download points at a bare IP instead of a domain, which is already a bad sign. An abuse confidence of 75 or higher blocks the request; 25 to 74 raises a warning; IPs on AbuseIPDB's own whitelist are left alone.

The free plan covers 1,000 checks and reports a day combined, and only raw-IP destinations are ever looked up.
One key

Domain intelligence

Background on the domain itself. One WhoisXML key unlocks three separate checks, and each one is switched on independently.

WhoisXML APIFree key

Registration detail for a domain: age, registrar, name servers, whether the ownership record is redacted, and which country it points at. Download Guard already estimates domain age through RDAP without any key — this replaces that thin answer with the full record, which is what separates a three-day-old download host from a boring old one.

Sign-up comes with a small free credit balance; check their pricing page for the current amount, as it changes. All three WhoisXML checks below draw on that same balance, so it goes three times as fast if you switch them all on.
WhoisXML Domain ReputationSame key

Scores a domain for safety and surfaces the malware and phishing blocklists it appears on. A low score or a blocklist hit raises the risk WardenOne assigns to the page or download rather than blocking on its own.

No second key. Uses the WhoisXML key above, but stays off until you press its own Test button.
WhoisXML Threat IntelligenceSame key

Indicator-of-compromise matching against known malicious domains, URLs, and IPs, with the threat type attached. An IoC match here is treated as confirmed and blocked.

No second key. Uses the WhoisXML key above, and also stays off until you press its own Test button.
Sign-up

How to get each key.

Every one of these is a free account on the provider's own site. WardenOne cannot issue keys and never sees your account — you register, copy the key, and bring it back to the popup.

Free tiers

Seven providers, six sign-ups

Start with OpenPhish, which needs nothing at all. Safe Browsing and VirusTotal give the biggest lift after that.

Nothing to getOpenPhish

There is no sign-up and no key. Open the popup, turn OpenPhish on, and press Test OpenPhish feed. WardenOne fetches the Community feed and caches it locally. Leave the token field empty unless you have a paid OpenPhish feed.

openphish.com
Free keyGoogle Safe Browsing

1. Sign in at the Google Cloud console and create a project (any name).
2. Open APIs & Services → Library, search for Safe Browsing API, and enable it.
3. Go to APIs & Services → Credentials, choose Create credentials → API key.
4. Copy the key. If the key is rejected later, it is almost always step 2 that was skipped.

console.cloud.google.com
Free keyVirusTotal

1. Create a free community account at virustotal.com and confirm the email.
2. Click your avatar, top right, and choose API key.
3. Copy the key shown there. The same key covers URL reports, the popup's link scanner, and file-hash lookups.

virustotal.com
Free keyURLhaus

1. Create a free abuse.ch account at auth.abuse.ch.
2. Open your account profile after signing in.
3. Copy the Auth-Key listed there. It is one key for all abuse.ch APIs, including URLhaus.

auth.abuse.ch, urlhaus.abuse.ch
Free keyAbuseIPDB

1. Register a free account at abuseipdb.com and verify the email.
2. Open Account → API.
3. Choose Create Key, give it a name such as WardenOne, and copy it. The key is shown once, so paste it straight into the popup.

abuseipdb.com
Free keyWhoisXML API

1. Sign up at whoisxmlapi.com with an email address.
2. Open the dashboard after confirming the account.
3. Copy the API key shown on the dashboard. One key covers domain records, domain reputation, and threat intelligence — you do not need three subscriptions.

whoisxmlapi.com
ApprovalPhishTank

1. Register an account at phishtank.org.
2. Sign in and open the developer section to request an application key.
3. Copy the key once it is issued. Unlike the others this is not instant, and PhishTank has periodically paused new registrations — if you cannot get a key, OpenPhish covers most of the same ground for free.

phishtank.org, checkurl.phishtank.com
Adding a key

Where the key goes.

Keys live in the popup, under Download Shield. Each provider has its own field, its own switch, and its own Test button.

In the popup

Paste it, test it, done

Open the WardenOne popup, scroll to Download Shield, and expand Advanced reputation providers.

Paste the key, then press Test.

Find the provider's row, paste the key into its field, and press its Test button. The status line underneath says whether the provider accepted it. A key that tests clean switches its check on; a rate-limited answer still counts as a working key and WardenOne retries later.

Download Shield Advanced providers Test button Stored locally

Keys stay on this device

Provider keys are saved in Chrome's extension storage on your machine, alongside your other WardenOne settings. They are sent only to the provider they belong to, as part of a check you enabled.

The two WhoisXML add-ons need their own Test

Domain Reputation and Threat Intelligence reuse the WhoisXML key, but they do not switch themselves on when the key changes. Press their own Test buttons to enable them.

Turning one off

Flip the provider's switch off and its lookups stop immediately. Clearing the field removes the key. Everything WardenOne does without providers keeps running either way.

Checking a link by hand

With a VirusTotal key saved, the popup's URL scanner takes any pasted link and checks it before you visit — useful for a link someone sent you.

Provider keys are optional. WardenOne protects you without them, and better with them. Developer: iri.dev
