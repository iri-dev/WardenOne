What can this page actually learn about you?

Every result here comes from running the probe twice on the same page — once where WardenOne's shields are running, and once where they are not — and comparing what came back. Nothing is read off a settings screen.

That distinction is the point. A test that printed a tick because a switch was on would keep printing it after a browser update quietly broke the thing underneath. If a shield ever stops working, the two readings start agreeing and this page says so.

What is deliberately not here. The referrer a third party receives, whether a third-party cookie survives, and whether a real tracker request is refused all need a server on the other end to answer honestly. This page has no server, so those are absent rather than guessed at — a green tick nobody measured is exactly the thing this page exists to argue against.
