Release history

Milestones and ongoing work.

  1. UnreleasedRolling build

    Ongoing refinements

    The changelog currently records work on build awareness, IP-logger warnings, onboarding guidance, performance and compatibility. Entries under “Unreleased” ship in the rolling build, not as a separate version.

    Read the current entries {{icon:arrow-right}}
  2. Version 1.0.22 October 2026

    More control and clearer status.

    • A searchable Settings page with categories, current protection state and site exceptions.
    • Backup and import for switches, lists and site choices, with a preview before import.
    • A build ID beside the version for official GitHub ZIPs, with repair results tied to that build.
    • Steadier settings saves and a number of compatibility fixes.
  3. Version 1.0.121 August 2026

    Broader guidance and quieter warnings.

    • A guide to getting your own optional API keys.
    • Download Shield no longer treats ordinary installers as dangerous by default.
    • More privacy-cleaning controls and fewer repeated warnings.
  4. Version 1.0.029 July 2026

    The first versioned milestone.

    The first release established the extension and its core browser protections. The full changelog keeps the detailed record.
