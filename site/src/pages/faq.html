Getting started

Where can I download WardenOne?
Use the download page, which points to the latest GitHub release from iri-dev/WardenOne. WardenOne is a ZIP of extension files, not an installer or an executable.
How do I install the ZIP?
Unzip it to a folder you will keep, open your browser's extensions page, turn on Developer mode and choose Load unpacked. Select the folder with manifest.json directly inside it. Leave Developer mode on afterwards: Chrome switches unpacked extensions off without it. The installation guide has the address for each browser.
Which browsers are supported?
WardenOne is built for Chromium browsers and documents Chrome, Edge, Brave and Opera. The manifest declares Chrome {{stat:minimumChrome}} as the minimum version. Browser differences can affect individual features, so include the browser and version in a bug report.
How do updates work?
Official GitHub ZIP builds can tell you when a newer complete build is available. To update, download and extract the latest ZIP, replace the files in your saved extension folder and press Reload on the extensions page. Settings → About WardenOne shows your version and build ID.

Protection and compatibility

Can WardenOne guarantee that a site is safe?
No. Blocklists can miss a new threat and behaviour checks can be uncertain. A warning is a reason to stop and look; the absence of a warning is not a safety verdict. How it works explains the layers and their limits.
Why did a legitimate site stop working?
A site may depend on a request or browser behaviour that a protection blocks. Try pausing WardenOne on that site, or turning off the relevant feature there for a moment. If you can reproduce it, report it with the site, browser version and control involved.
Will it interfere with video or music?
Media players are sensitive to blocking. WardenOne has dedicated handling for YouTube, Twitch and Spotify, plus compatibility exemptions and fail-open behaviour in selected cases. If playback fails, pause the relevant protection for that site and report the details.
Can I control protection for one site?
Yes. The popup and Settings provide site-level exceptions, and Site Firewall offers advanced per-domain rules. Advanced rules can break a page, so review what you changed and undo the rule if needed.

Privacy and trust

Does WardenOne need an account?
No. It runs without an account or a WardenOne cloud service. Your settings and activity record live in your browser's extension storage.
Does it send my browsing history to the developer?
No. WardenOne has no developer-run telemetry service. Some automatic maintenance requests and optional provider lookups still reach outside services; the privacy overview explains the difference, and the full policy lists every detail.
What do optional reputation checks share?
When you enable them, automatic reputation providers can receive the addresses of pages you open. They are off by default. Review each provider and its data flow in Settings and the privacy policy before turning one on.
Is WardenOne open source?
Yes. The extension, website source, tests and bundled rules are published in the official repository under the GNU GPL v3 or later. Some upstream lists have their own rights and credits; see Credits.
How can I tell a fake download from the real one?
The only official source is github.com/iri-dev/WardenOne. A WardenOne .exe or setup program is not genuine. Read the fake download incident notice if you may have run one.
