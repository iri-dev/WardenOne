Router-level safety guide

Make protection harder to bypass.

WebWarden protects the browser. DNS filtering protects the network underneath it, blocking risky domains before pages, apps, consoles, or phones can connect.

Why this layer matters

A browser extension can be disabled, bypassed, or missed by another app. DNS filtering sits earlier in the chain.

Defense in depth

DNS is the safety floor.

Keep WebWarden for page-level protection, redirects, downloads, cookies, and session checks. Add DNS filtering so obvious adult, malware, phishing, and scam domains are stopped before a browser decision even happens.

Step 2

Apply it where it matters.

Router setup is strongest because every device that joins the Wi-Fi gets the same filtering automatically.

Best option

Set DNS on your router

  1. Open your router admin page, usually 192.168.1.1 or 192.168.0.1.
  2. Log in using the router sticker, ISP app, or admin password.
  3. Find DNS settings under Internet, WAN, LAN, or DHCP.
  4. Replace the DNS servers with your provider's two addresses.
  5. Save, reboot the router, then reconnect your devices.
Per-device fallback

Use this if router access is blocked

  1. Windows: Settings → Network → DNS server assignment.
  2. macOS: System Settings → Network → DNS.
  3. iPhone / Android: use the DNS provider profile or app.
  4. Chrome: turn off Secure DNS, or set it to the same provider.

Per-device setup is useful for laptops and phones, but router setup is still the cleanest home-network option.
