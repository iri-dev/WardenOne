Core

Blocking and page protection

Coverage for malicious pages, redirects, trackers, token theft, popups, and injected page threats.

<all_urls>Required

Gives WardenOne coverage on the sites you visit so phishing, tracker, download, redirect, and session protections do not miss pages.

Whole-web access is used for whole-web protection. Settings and activity remain local by default.
declarativeNetRequestCore

Lets Chrome enforce fast block rules for ads, trackers, phishing, malware, scam, and IP-grabber domains.

Chrome applies these rules locally through its rule engine.
activeTabCurrent tab

Lets popup actions and scans work with the tab you are currently viewing.

Used for active-tab context, especially when you start a scan or action.
scriptingPage shield

Applies page-level protection such as overlay cleanup, form trap detection, token checks, and trusted-site adjustments.

Used when page behavior cannot be handled by network rules alone.
webRequestDetection

Detects risky redirects, suspicious beacons, token exfiltration attempts, and download chains that static lists cannot fully explain.

Used for security signals and local decisions, not advertising profiles.
webNavigationNavigation

Watches page movement so WardenOne can catch redirect chains, fake login hops, popups, and risky landings.

Used to understand scam flows and block suspicious navigation paths.
Local

Storage, upkeep, and alerts

Saving choices, running maintenance, showing warnings, and supporting local review screens.

storageLocal

Saves settings, list metadata, activity, allowlists, trusted sites, API keys, local learning data, and installed-extension change/review snapshots.

Stored in Chrome extension storage on your device. Extension IDs and review decisions are not uploaded.
alarmsLocal

Schedules list refreshes, startup checks, extension-inventory reconciliation, retry checks, provider cache cleanup, and maintenance tasks.

Used for quiet background upkeep inside the extension.
notificationsAlerts

Shows local warnings when a threat is blocked, a risky extension changes, or a security check finishes.

Used for visible safety feedback on this browser.
historyLocal

Supports activity context, cleanup tools, startup review, and redirect investigation.

Used inside local views and checks. WardenOne does not upload your browsing history.
On request

Review and cleanup

Used when you review installed extensions, clean site data, control site settings, or inspect downloads.

browsingDataCleanup

Powers privacy cleaning, emergency sign-out, site data clearing, cache cleanup, and session reset actions.

Used when you run cleanup tools or emergency logout.
cookiesCleanup

Supports strict cookie controls, session safety checks, Forget Me, and emergency logout cleanup.

Used for cookie safety and cleanup, not for selling or sharing browsing data.
managementReview

Builds the local Extension Security Centre from exact IDs, versions, enabled state, install type, Chrome permission warnings and access changes. The centre can disable an extension or ask Chrome to confirm removal only after you press that extension's button.

Exact-ID local intelligence is separate from permission risk. WardenOne cannot read another extension's source or prove an unknown extension safe.
contentSettingsSite control

Reads or adjusts camera, microphone, notifications, cookies, JavaScript, images, and other site permissions.

Used by the site permission scanner and per-site controls.
Core

Downloads and tabs

Protecting files, opening review pages, and applying controls to the right browser tab.

downloadsGuard

Checks risky downloads, pauses suspicious files for review, and lets you cancel or continue with context.

Used by Download Shield to protect file starts and download sources.
tabsTabs

Applies per-tab protection, opens review pages, handles tab-limit tools, and avoids touching protected tabs incorrectly.

Used so protections follow the tab you are actually using.
tabGroupsTabs

Works with tab organization tools and tab-aware protection when grouped tabs need to be handled safely.

Used for Chrome tab group context, not page content collection.
External services

What can leave the browser.

These host permissions support reputation and threat intelligence checks. They exist for specific safety features, not as background tracking endpoints.

Opt-in checks

Reputation and intelligence providers

These endpoints support specific safety checks. They are not used as background tracking pipes.

Breach checksHave I Been Pwned

Used only when you click Check breach history. Sends the site's registrable domain to look up that site's public breach record — not your account, and not any password.

haveibeenpwned.com
Password exposurePwned Passwords

Used only when you type a password into Check password exposure and press the button. The password is hashed on your device and only the first five characters of the hash are sent; the service replies with every suffix in that bucket and the match is made locally. The password and the full hash never leave your machine, the request carries no cookies and no referrer, and the answer is written nowhere. WardenOne does not read what you type into web pages.

api.pwnedpasswords.com
Domain ageRDAP and WhoisXML

Used for registration age and reputation clues when a new or suspicious domain asks for passwords or serves risky downloads.

rdap.org, www.whoisxmlapi.com, domain-reputation.whoisxmlapi.com, threat-intelligence.whoisxmlapi.com
URL reputationGoogle Safe Browsing

Optional URL reputation checks when you provide and enable your own API key.

safebrowsing.googleapis.com
File hash checksVirusTotal

Optional URL and file-hash reputation. WardenOne can check a hash without uploading the downloaded file.

www.virustotal.com
Phishing feedsPhishTank and OpenPhish

Optional phishing intelligence for known malicious links, forms, pages, and download flows.

checkurl.phishtank.com, raw.githubusercontent.com/openphish/public_feed
Malware sourcesURLhaus and AbuseIPDB

Optional malware URL and abusive IP checks for suspicious servers, raw IP addresses, and risky download sources.

urlhaus-api.abuse.ch, api.abuseipdb.com
